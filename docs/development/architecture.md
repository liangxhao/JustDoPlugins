# 架构与隔离边界

仓库按 `plugins/<type>/<name>/` 管理 extensions、skills、mcp-servers、hooks 四类独立插件，详见[插件分类与列表](../plugins/README.md)。本文描述当前 `plugins/extensions/` 中两个扩展的架构。

## 扩展与 MCP App

当前两个插件是独立的 OpenClaw 原生扩展，通过 `openclaw.plugin.json` 声明附带的 stdio MCP 服务。
OpenClaw 管理相对安装路径、服务启动与停止；卸载或停用扩展会撤下相应的服务和应用入口。
业务工具由 MCP 服务提供，共享服务与界面代码集中在仓库的 `shared/` 目录。

应用前端编译为单个 `app.html`，服务编译为独立的 `server.cjs`。
交付包包含执行需要的静态资源，运行时不安装 npm 依赖；OpenClaw 扩展入口使用宿主提供的公开 SDK。
插件清单与扩展入口负责接入，模型调用和界面操作复用同一套 MCP 服务。

普通扩展无需提供 MCP App。增加交互界面时，按[MCP App 开发与宿主接入](mcp-app-development.md)实现身份与来源校验和标准界面协议；启动入口、图标和文件能力按需选择，验收见[接入 checklist](mcp-app-checklist.md)。

## 数据与并发

默认数据在用户目录 `.local-mcp-apps/univer/documents.sqlite` 和
`.local-mcp-apps/perspective/documents.sqlite`，可分别通过环境变量 `MCP_APP_DATA_DIR`
指定目录。这里保存应用文档，不保存聊天、模型凭据或原生执行状态。
文档库是当前用户的跨会话文件集合，并非当前对话的消息列表。

保存使用 SQLite 原子更新和 revision 比较；不同窗口或模型的旧版本保存会被拒绝，
不会覆盖较新数据。遇到冲突，先复制/导出尚未保存的内容，再按重新读取。
当前不自动合并或后台自动保存。工具结果打开文档时重新读取最新存储，重启服务后可继续打开。
持久化大小和数据规模限制由各插件分别定义，具体上限见插件详细文档。
打开界面的工具只返回文档标识和版本，App 再通过当前视图读取最新数据，避免把大工作簿重复保存在原生视图租约中。
Perspective 的全部持久化入口先在离线 Worker 中建立真实引擎视图，校验筛选、聚合与表达式；失败不写数据库，校验后仍以原子 revision 比较保存，避免并发覆盖。校验队列、运行时间和资源生命周期有界，日志不进入 MCP 标准输出。
展示设置通过随包插件的公开动态样式规范及格式化接口校验；仅为生成规范提供局部默认主题和不可渲染的适配，不改变查询引擎的全局环境。MCP 取消信号贯穿校验队列及最终写入检查，关闭后不接受迟到提交。分析源表的列类型随文档保存，数据编辑、全空列及筛选后的视图不会改变源数据身份。

## 离线与隔离

两个应用都通过标准 MCP Apps `ui://` 和 AppBridge 交互。`open_editor` 额外声明
原生支持的 App-only global 入口，声明无需模型调用的启动能力；普通 MCP Apps 客户端仍可调用创建工具。

编辑器静态 JS、CSS、WASM、字体全部内嵌在交付文件中。MCP 子进程启动一个随机端口的
`127.0.0.1` 静态页面，URL 使用每次启动重新生成的随机路径，检查 Host 和精确路径，
不提供文件浏览、任意路径或公网代理。资源声明只放行这一个本机 frame origin。
该页面自己的 CSP 只允许内嵌脚本、Blob 模块/Worker 和 WASM，禁止网络连接和表单提交。
外层桥只在确切的父窗口与该编辑 frame 之间转发 JSON-RPC，不改变 OpenClaw 的 CSP。
原生 opaque 内容的后代 frame 同样具有 opaque origin，因此 App 内部 relay 允许该
精确子窗口的 `null` origin，并使用 opaque receiver 必需的通配 target；宿主通道保持精确 origin。
进程退出后本机静态服务关闭。该设计不需要运行时 patch。
发布本机资源 origin 前筛选浏览器禁用端口，关闭不合适的监听后有界重试；不会重放创建或保存工具。

应用选择会以有界上下文反馈给当前模型；是否内网推理由宿主模型配置决定。
上下文同步独立于文件读取和保存：后台视图被宿主拒绝同步时，不覆盖文件状态，也不重试业务工具。
本地文件仅通过用户选择、原生会话授权的文件资源或模型明确传入的数据进入工具，不开放任意本机文件路径读取。
外部网络受 CSP 阻止不等于所有上游功能都可离线，未支持的地图/外链不应作为市场能力宣传。

## 当前内容与连续修改

已保存文档工具与当前浏览器实例的 App 工具分开。`shared/live-app.ts` 使用标准 AppBridge 工具协商，提供有界 snapshot/query、按内容戳 apply 和标记了 `workspace/prepare-context` 的发送前准备。内容戳验证当前文档、实例代次、编辑计数和完整快照，不能替代原生会话授权。成功 apply 表示编辑器已应用，仍需主动保存；未确认修改不重放。

Univer 在同一实例中使用一条可撤销的原生命令修改单元格、样式或表格结构。Perspective 在真实引擎中校验配置后修改当前 viewer，query 读取实际过滤、分组及聚合结果，并限制行列窗口。发送前准备提交单元格输入并等待上下文同步，不执行业务工具或发送消息。

App 的当前实例 save 使用同一内容戳、操作 ID 防重放及界面持久化路径；普通保存使用 revision CAS，来源文件只提供明确的本地副本模式，不新增源写回入口。确认保存与后续读取分别报告，当前输入或副本打开失败不能抹去已确认的保存事实。手动新建和打开工具返回引用时，界面按精确 ID 读取一次当前内容，不重放创建操作。

可选后台上下文合并最新请求，并与显式 prepare 共用串行通道；请求序号会淘汰晚于新准备完成的旧描述。文档库同步无活动文档状态，不遗留上次打开的对象作为当前目标。上下文仍不构成授权或持久化事实。

工具结果按顺序处理，重复旧 revision 不重建编辑器；新编辑器成功加载后才替换旧内容，失败保留旧实例。关闭后撤下事件并拒绝旧操作。持久化恢复仍只覆盖已保存文档，不恢复已销毁的草稿、撤销栈或原生历史回执。接口细节见[能力审查](app-capabilities.md)。
实时工具从提交输入前至操作完成暂时锁定画布；文档切换从离开确认到加载完成保持保护。保存请求等待期间允许继续编辑，返回后重新提交输入并比较内容，保留新编辑及未保存状态；保存副本遇到新编辑时不切换实例。
