# Perspective 扩展

Perspective 是独立的 OpenClaw 离线数据分析扩展，附带 MCP App。扩展标识为 `perspective-app`，MCP 服务名为 `perspective`，当前版本为 0.1.0。

使用 [Perspective](https://github.com/perspective-dev/perspective) 5.6.0 的官方 `@perspective-dev/*` 包，不使用已停止维护的 `@finos/*` 包。
WASM 查询引擎、表格和图表资源随交付包提供，运行时不依赖外部数据服务。

## 安装与打开

安装 Perspective 的完整交付目录或对应 `.tgz` 文件，完成扩展审查并启用。仓库生成的独立导入目录为 `dist/plugins/extensions/perspective/`，压缩包位于 `dist/archives/extensions/`。
包内包含原生清单、扩展入口、说明和完整 `dist/`，运行使用宿主的 Node 24，无需安装 npm 依赖或联网。

启用后附带的 MCP 服务由 OpenClaw 管理，可通过手动应用入口或模型工具打开。
本地文档库支持新建、导入和重新打开分析文档；空白文档导入数据后开始分析。
停用或卸载父扩展会撤下服务和应用入口，已保存的用户文档保留。
服务和工具提供随包的明暗 SVG 图标；原生 `skills/tabular-analysis/` 提供按需加载的分析任务与真实工具说明，随扩展启停，不改变宿主权限。

## 基本使用

1. 从手动入口导入 CSV、TSV、JSON、NDJSON 或 Arrow，也可让 agent 提交实际记录，或打开宿主授权的文件。
2. 选择分组、透视、筛选、聚合和图表；用“新增图表”“复制”“关闭图表”管理最多 8 个面板，选择左右、上下或标签页布局。
3. 将概览图设为“点击联动”，点击其数据后查看明细图同步过滤；“清除联动”恢复完整结果。原生图例、提示、图表缩放和表格列设置继续可用。
4. 点击保存以持久化源数据、所有面板、布局、样式和联动筛选；从导出格式菜单选择图像、数据或完整分析文档。
5. 从文档库重新打开分析，继续使用已保存的工作区。

示例：“用 Perspective 分析以下各部门预算数据，按部门汇总并展示图表……”
输入应是实际 JSON records，不生成虚构业务数据；模型上下文和是否内网推理由宿主模型配置决定。

支持可选展示扩展 `ui/shared-header` v1：与支持该能力的宿主协商后，共用单行标题区域，分析画布保留完整宽度，保存与导出仍在插件内执行。可通过重命名按钮修改文档标题，再主动保存。宿主不支持、未提供或撤回布局时，恢复完整的独立标题栏，当前编辑器与未保存内容保留。

### 图表覆盖与上游边界

本扩展复用官方 Datagrid 和 `viewer-charts`，仅注册以下 14 种离线展示器。

| 类型     | 展示器                          | 主要用途                                     |
| -------- | ------------------------------- | -------------------------------------------- |
| 表格     | `Datagrid`                      | 多级分组、透视、合计、直接数据编辑与条件格式 |
| 分类图表 | `X Bar`、`Y Bar`                | 横向条形、纵向柱形及分系列比较               |
| 趋势     | `Y Line`、`Y Scatter`、`Y Area` | 折线、分类散点和堆叠面积                     |
| 数值关系 | `X/Y Scatter`、`X/Y Line`       | 数值散点/气泡与按 X 排序的连续曲线           |
| 密度     | `Density`                       | 密集采样点的二维分布                         |
| 层级     | `Treemap`、`Sunburst`           | 矩形树图与旭日图，按层级展示正数面积/占比    |
| 矩阵     | `Heatmap`                       | 分组与分割维度交叉形成的热力矩阵             |
| OHLC     | `Candlestick`、`OHLC`           | 开盘、收盘、最高、最低四列的蜡烛/刻线表示    |

这些展示器有真实界面图集验证：MCP 创建、保存重开、查询、下载，并在图片导出前检查屏幕绘图区。PNG 使用独立临时渲染实例，避免上游原生导出重绘清除主图的点击选区与联动筛选；导出后清理临时实例和视图。

`Map Scatter`、`Map Line`、`Map Density` 依赖联网底图，因此不注册、不接受配置。WebSocket、数据库 Virtual Server、远程数据源、上游内嵌模型代理与 API key 也不接入；agent 使用宿主已有的认证 AppBridge 工具操作当前分析。

全部面板共用当前文档的一张本地源表。点击联动只接受源列维度；计算列可在图中使用，但点击其私有维度时会提示并保留现有联动条件，避免把别的面板无法识别的表达式别名写入全局筛选。上游派生表 DAG、多表 joins、Python/Jupyter/React 集成、图表运行时缩放或 pin 选区的重启恢复，以及完整格式组合尚未承诺支持。原生面板右键菜单可能创建未支持的表绑定，因此由插件的面板操作控件替代；表格左键列样式、排序、分组展开和图表点击交互保留。表达式、窗口和样式通过锁定版本的真实引擎与动态规范校验，仍不意味着所有组合均已验证。

CSV 导入保留字符串编号的前导零；只有整列都可安全识别为数字时才作为数值列。
超出 JavaScript 安全精度的编号保留为字符串。数据行多于表头的字段会被拒绝，避免静默丢列。
从全部记录建立显式列类型，后续记录中的列和首行空值不会被遗漏。单列中的非空值须为一致的字符串、数值或布尔类型；混合类型明确拒绝。数值按浮点列处理，避免 32 位整数截断。
文档同时保存 `schema`（`float`、`integer`、`boolean`、`string`、`date`、`datetime`），全空列仍保留类型。普通 records 按全部记录推断，数字默认浮点；`integer` 必须是 32 位整数，避免引擎静默截断。日期显式声明，`date` 接受有效 `YYYY-MM-DD` 或 UTC 零点毫秒，`datetime` 接受带时区 ISO 时间或整数毫秒；持久化统一为 UTC 毫秒。初始全空数值列可指定 `schema: { "金额": "float" }`。表格直接编辑会标记未保存，保存读取真实源表，独立于筛选聚合结果。

Arrow 支持 IPC stream/file、字典、多个批次及 LZ4/ZSTD 缓冲压缩。支持的物理数据为整数、32/64 位浮点、布尔、UTF-8 字符串、日期和秒/毫秒时间戳；微秒/纳秒时间戳、decimal、binary、嵌套结构及 view/run-end 编码明确拒绝，避免静默舍入。超过精确 JSON 整数范围的数据拒绝；安全但超出 32 位整数范围时，可显式选择 `float`，精确标识符应使用字符串。日期限定四位 ISO 年份，时间精度为毫秒。日期或秒级时间戳需在引擎前验证原始值域，因此其数据缓冲真正压缩时会拒绝并提示导出无压缩 Arrow；普通标量与毫秒时间戳支持上述压缩。
稀疏记录缺失的字段作为空值处理；`constructor` 等普通列名可用。`__INDEX__`、`__ROW_PATH__` 是引擎保留字段，源列及表达式不能使用，需先改名。
替换源数据默认保留已经保存的视图配置；不再存在的列会被拒绝，可在同次 `replace_data` 中提供新的 `config`。
追加记录保留现有列类型并推断新增列；替换记录保留仍存在的同名列类型，可显式提供 `schema` 改变类型。替换时移除未再出现的旧列，保留的配置仍须有效。

## MCP 工具

| 工具                               | 用途与调用约定                                                                                            |
| ---------------------------------- | --------------------------------------------------------------------------------------------------------- |
| `analyze_data`                     | 从非空 JSON records 创建分析，最多 5000 行、100 列；可提供 `schema`、`config` 或 `workspace` |
| `import_analysis`                  | 导入 `format: json/columns/ndjson/csv/tsv/arrow`；提供 `text` 或 base64 `blob`，支持显式类型及初始工作区 |
| `list_visualizations`              | 发现真实离线图表名称、分类及有序列角色，避免猜测图表参数 |
| `inspect_analysis`                 | `id` 或临时 `data` 二选一；按 `panelId`、`plugin`、`column` 获取样式规范，或通过 `section` 查询本地表达式/窗口/配置参考；不保存 |
| `query_analysis`                   | 按 `panelId` 查询已保存工作区的真实聚合结果，支持行列分页 |
| `configure_workspace`              | 按 revision 修改面板、布局、当前面板、联动主图、全局筛选与配色；`panels` 整体替换 |
| `replace_data`                     | 用非空记录替换已有数据，提供当前 `expectedRevision`；保留已保存的视图配置                                 |
| `append_data`                      | 按当前 revision 追加记录，保留配置并重新校验总容量和列类型                                                |
| `configure_analysis`               | 按 revision 修改指定 `panelId`（默认当前面板）的原生分析配置；省略设置保留 |
| `read_analysis`                    | 已保存的 schema、配置及源记录分页，参数 `id`、`offset`、`limit`、`includeConfig`，默认 25 行、最多 100 行 |
| `list_documents`                   | 列出当前本地分析文档                                                                                      |
| `open_document`                    | 按文档 ID 打开分析                                                                                        |
| `read_document`                    | 读取最新数据和版本，模型修改前应先调用                                                                    |
| `open_editor`                      | 打开手动入口与本地文档库                                                                                  |
| `new_document`                     | 新建空白分析文档                                                                                          |
| `import_document`、`save_document` | App-only 文档导入与保存接口                                                                               |
| `preview_file`                     | App-only 文件入口，支持上述本地格式，仅读取宿主签发的 `openclaw-file://` 资源 |

更新前读取最新 revision，旧版本写入会被拒绝，不会覆盖其他窗口的较新修改。
当前不自动合并或后台自动保存；遇到冲突，先保留或导出当前内容，再重新读取。

配置参数使用 Perspective 原生字段，例如 `group_by: ["部门"]`、`columns: ["金额"]`、`filter: [["金额", ">", 100]]`、`aggregates: { "金额": "sum" }`、`plugin: "Y Bar"`。数组替换对应设置；未知字段、未知列、未随包注册的图表及 `table` 重绑定会被拒绝。

过滤条件采用 AND。锁定版本的 viewer 不能可靠往返保存 `filter_op: "or"`，因此接口拒绝该值；需要 OR 时，用布尔表达式列组合条件后筛选为真，以保持界面和服务查询一致。

所有创建、导入、保存、配置及数据替换/追加均在写入前通过随包的真实查询引擎校验表达式、筛选与聚合；失败不创建文档或增加 revision。校验不联网，使用有界的独立 Worker，最多 16 个待处理请求、每个运行最多 15 秒；失败后重新建立引擎，不重放写入。
图表与列样式复用随包插件的动态规范，校验选项、范围、颜色语法及实际数值/日期格式构造；非法样式不会保存为无法打开的文档。跨图表切换时保留合法的隐藏样式。校验或请求被取消后不写入，关闭服务时清理待处理请求。

`read_analysis` 的完整结构化结果最多 256 KiB（UTF-8）；超出时缩小行数，配置很大时使用 `includeConfig: false`，结果以 `configOmitted: true` 标记。未指定时仍返回配置。

## 当前分析接口与对话准备

以下是当前浏览器实例通过标准 AppBridge 提供的 App 工具，与 stdio 文档库工具分开；宿主先以当前原生会话和已准入的确切桥选择实例，再发现和调用这些工具。文档 ID 与内容戳不构成授权。

| App 工具            | 参数与结果                                                                                                                |
| ------------------- | ------------------------------------------------------------------------------------------------------------------------- |
| `prepare_context`   | 无参数；以 `workspace/prepare-context: true` 标记，等待当前数据与配置摘要通过 `updateModelContext` 同步后确认             |
| `analysis_snapshot` | 当前身份、内容戳、类型、`activePanelId`、面板摘要、工作区和有界预览；大工作区可能省略，精确内容用 inspect |
| `analysis_query`    | 可选 `panelId`；行列窗口默认 25×20、最大 100×20；读取实际聚合结果，包含当前点击联动过滤 |
| `analysis_inspect`  | `kind: workspace/plugins/style/source/selection`；读取未保存工作区、图表角色、样式/计算参考、源数据页或选区；不保存 |
| `analysis_apply`    | 内容戳与唯一操作 ID；`patch` 可含 `panelId/config`、`workspace`、`cells`、`append` 或 `rows`；只修改当前实例，主动保存后持久化 |

例如，在新快照上以唯一操作 ID 提交 `patch: { "config": { "group_by": ["部门"], "columns": ["金额"], "aggregates": { "金额": "sum" } } }`。成功返回 `{ "operationId": "…", "status": "applied", "snapshot": { … } }`，说明界面确实应用，仍须主动保存。配置先在真实引擎中校验；更新失败尝试恢复原配置，不伪报成功。

多图示例（`workspace.panels` 为完整面板集合，各面板共用本地源表，不传 `table`）：

```json
{
  "workspace": {
    "panels": {
      "overview": { "plugin": "Y Bar", "group_by": ["部门"], "columns": ["金额"] },
      "detail": { "plugin": "Datagrid", "columns": ["部门", "金额"] }
    },
    "activePanel": "overview",
    "masters": ["overview"],
    "layout": {
      "type": "split-layout", "orientation": "horizontal", "sizes": [1, 1],
      "children": [
        { "type": "tab-layout", "tabs": ["overview"] },
        { "type": "tab-layout", "tabs": ["detail"] }
      ]
    }
  }
}
```

`workspace` 可单独修改布局、全局过滤或 `masters`，保留当前图表实例；显式替换 `panels` 才重建面板集。`activePanel` 用稳定面板 ID，标题不用于定位。`config` 在多面板文档中仅是当前面板的兼容镜像，持久化与校验以 `workspace` 为准。`analysis_inspect(kind: style)` 支持 `section: styles/expressions/windows/configuration/all` 与 `search`，先发现字段及角色，再提交样式、表达式或窗口配置。

源数据修改使用 `cells: [{row: 0, column: "金额", value: 120}]`（最多 2000 项）、`append: […]` 或 `rows: […]`；当前实例只允许现有列与声明类型，改变列结构应导入文档或使用已保存数据工具。修改前预检整个工作区，旧内容戳仍拒绝；当前源文件保持只读。

query 读取当前筛选、分组、透视和聚合后的结果，不把源记录当作聚合输出；`__ROW_PATH__` 表示分组路径。单次结果最多 256 KiB，超出时缩小窗口。快照和上下文最多 16000 UTF-8 字节，预览长文本最多 240 字符；超限时返回 `previewOmitted: true`，精确值用 query 分页取得。

内容戳检查文档、编辑器代次、编辑计数及完整快照，每个实例保留最近 8 个戳和最多 128 个操作 ID。错误目标、用户并行修改、过期戳、重复操作或已关闭实例均返回 `isError: true`。应用结果未知时不自动重放；发送前同步被拒绝或同步期间又发生编辑时，不报告准备成功，也不自动保存或发送消息。

## 文件探索与保存副本

文件入口只读取宿主为当前视图签发的 CSV、TSV、JSON、NDJSON/JSONL 或 Arrow/Feather 资源，不接受任意本机路径。单个文件最多 2 MiB，支持标准 blob 和 UTF-8 text 资源响应。JSON 可以是 records、列数组或包含 `rows`、`schema`、`workspace` 的分析文档。

打开后可筛选、分组和修改图表，源文件保持只读；即使资源附带写能力也不会写回。点击“保存副本”将源数据和整个工作区创建为本地文档。“重新读取”需要确认放弃修改。数据导出针对当前面板；完整分析 JSON 包含源数据与工作区，可重新导入。静态 HTML 只含转义后的结果表格，不加载脚本或 CDN。
保存等待期间可以继续编辑；返回后若出现新修改，保留当前分析并提示副本已保存、新修改仍未保存，不切换到较旧副本。读取当前内容、应用配置和切换文档时暂时锁定编辑区，防止等待期间覆盖新输入。

## 容量与兼容限制

| 项目                 | 上限或约束                                                    |
| -------------------- | ------------------------------------------------------------- |
| 数据记录             | 5000 行                                                       |
| 全部记录涉及的列     | 100 列                                                        |
| 持久化文档（含配置） | 2 MiB                                                         |
| 本地分析面板         | 最多 8 个，同一源表；可全部关闭后重新新增 |
| Arrow 解码预检       | 解压前检查 IPC 批次行数、字段和缓冲区声明；展开预算 16 MiB，解码后源数据仍限 2 MiB |
| 导出结果             | 最多 20000 行、200 列及 500000 个单元格，超过时先缩小分析视图 |
| 地图、外部数据连接   | 不属于离线版支持范围                                          |

没有远程数据库、大数据后端、云端分享或多人协作。不支持将引用外部地址的上游视图当作可离线使用的功能。
本插件用于数据分析，不提供 XLSX 预览或源文件写回接口。

## 本地数据

分析文档保存在用户目录下的 `.local-mcp-apps/perspective/documents.sqlite`，可通过 `MCP_APP_DATA_DIR` 指定数据目录。
保存的是实际源数据与视图配置，不保存聊天、模型凭据或原生执行状态；文档库跨会话使用。
重启服务后可继续打开已保存的文档，其他窗口的修改需重新读取后显示。
重复的同版本结果保持当前实例；新内容加载失败保留旧编辑器。恢复范围为已保存文档，已销毁实例的未保存配置不持久化，也不提供原生聊天历史回执恢复。

备份前先停用服务，再复制整个数据目录，包括 SQLite WAL。卸载扩展不自动删除用户文档。
