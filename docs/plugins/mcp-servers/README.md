# MCP Servers 独立服务

收录独立配置与运行的 MCP 服务。当前暂无独立 MCP 插件；Univer 和 Perspective 附带的服务由各自原生扩展维护，见[Extensions 列表](../extensions/README.md)。

源码位于 `plugins/mcp-servers/<name>/`。新增服务时在 `docs/plugins/mcp-servers/<name>/README.md` 说明启动方式、配置、工具和权限边界，并在本页登记；需要 npm 依赖时使用根目录工作区与锁文件。
现有扩展 App 构建、规范测试和打包流程不处理本目录。

参见[插件分类与列表](../README.md)和[开发指南](../../development/README.md)。
